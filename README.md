本仓库已新增原生微信小程序及Node24/SQLite服务端。请先阅读 [微信交付与运行说明](docs/WECHAT_DELIVERY.md)，以及 [数据采集任务](docs/DATA_COLLECTION.md)、[Codex继续执行说明](docs/CODEX_HANDOFF.md)。

新小程序已接入用户提供的价格归档，缺失的重量基准、车型映射及报价口径会明确标注。**下方旧H5说明仅适用于dist目录；其中Mock数据与公式不用于新小程序。**

## 原H5演示说明

面向客户演示的手机端 H5 Demo，展示动力电池金属材料构成估价、统一评估报告和轻量化回收交易流程。当前为第二版，临时品牌“循电”及全部视觉素材均为项目内原创演示资产。

## 本地启动

需要 Node.js 18 或更高版本。Windows 可双击 `启动本地开发.bat`，也可以在仓库根目录执行：

```powershell
node dev-server.js
```

然后访问 <http://127.0.0.1:8080>。服务端对无扩展名路径提供 SPA 入口回退，刷新页面仍可正常打开。也可直接双击 `打开演示.bat` 查看静态版本。

运行轻量自动化检查：

```powershell
node check.cjs
```

如需重复执行真实浏览器交互检查，先以 `--remote-debugging-port=9222` 启动 Chrome，再运行 `node browser-check.cjs [截图输出目录]`。脚本会验证桌面/手机布局、完整估价、历史报告复用、普通报价保存、弹层边界、SPA 回退和浏览器运行时错误。

## 主要演示路径

1. 首页查看原创轮播图，点击“开始评估”或“填入示例”。
2. 选择品牌、车型、年份和 Demo 电池型号，可选填省份与里程。
3. 生成统一的评估报告，查看车辆、电池包、化学体系、七类金属材料构成、公式和估值区间。
4. 从首页或“我的”进入历史报告列表，打开任一记录进入同一个报告详情组件。
5. 从“交易”浏览普通报价和竞拍演示标的；普通报价可保存到本机并在“我的 → 历史报价”查看。
6. 在报告详情使用“分享报告”演示交互，或带入摘要发起回收信息。

## Demo 范围与 Mock 数据声明

- 所有车型、电池型号、电池参数、材料比例、参考单价、回收系数、金额和交易记录均为 Mock 数据。
- 所有页面均明确标注“Demo 模拟数据”；结果仅用于产品功能演示，不构成实际交易或回收报价。
- 未接入实时行情、权威数据库、真实车辆检测、真实用户或企业资质系统。
- 锂统一使用“折金属锂当量”口径及其对应参考单价，不与碳酸锂或电池级碳酸锂价格混用。
- 未列材料可包括电解液、石墨、隔膜、塑料、结构件及其他材料，因此明细占比不要求合计为 100%。
- 交易仅展示列表、详情、普通报价本地保存、历史记录和竞拍状态；不支持实时竞价、支付、资金托管、物流交割或真实履约。
- 浏览器数据保存在 `localStorage` 的 `battery-demo-v2` 项中，不会发送到服务器。

## 数据与代码位置

- `dist/app.js`：三组 Demo 电池、材料目录、估价公式、报告与交易交互。
- `dist/style.css`：手机壳、独立滚动、底部导航、容器级弹层与响应式布局。
- `dist/assets/`：临时 Logo 和五张原创 SVG Banner。
- `dist/index.html`：单页入口，弹层、Toast 根节点均位于手机容器内部。
- `check.cjs`：零依赖、可重复执行的公式与主要页面检查。
- `browser-check.cjs`：基于浏览器 DevTools 的真实交互、布局边界和截图检查。
- `dev-server.js`：零依赖本地静态服务，默认地址 `127.0.0.1:8080`。
