# 循电 · Battery Recycling DEMO

首版手机竖屏交互演示。临时品牌“循电”，可替换。

## 打开

Windows下直接双击 `打开演示.bat`，无需安装环境或登录GPT。需要修改和调试时，安装Node.js后双击 `启动本地开发.bat`，浏览器将打开 `http://127.0.0.1:8080`。完整操作见 `本地开发说明.md`。

也可以直接双击 `dist/index.html`，使用现代浏览器打开。数据保存在当前浏览器；不同浏览器、地址或设备的数据不共享。

## 演示顺序

1. 首页“填入示例”→开始估价→立即估价。
2. 查看材料、梯次估价与参数报告。
3. 我的→历史报告→打开同一报告，编号与内容不变。
4. 结果页→发布出售，填写价格和地区后发布。
5. 交易页浏览供求与竞拍。普通报价可本地保存；竞拍仅展示。
6. 条件估价→填入示例→生成双估价报告。

## 范围与限制

- 纯HTML、CSS、JavaScript，没有后端、真实支付或微信接口。
- 样例车型、电池参数、价格及交易信息均为模拟，不代表市场报价或真实车辆规格。
- 竞拍不实现提交、多人竞价、付款及交割。
- 型号选择以演示下拉列表实现；扫码使用样例，不调用摄像头。
- 参数报告可调用浏览器打印／保存PDF。历史报告与成功页复用正文。
- 临时视觉与首版交互用于评审，不代表正式生产版本。

## 文件

- `dist/index.html` 页面入口
- `dist/style.css` 视觉样式
- `dist/app.js` 样例、交互、模拟估价与本地保存
- `.openai/hosting.json` 演示站点配置
- `打开演示.bat` 无环境直接查看
- `启动本地开发.bat` Windows本地开发入口
- `dev-server.js` 零依赖本地网页服务
- `本地开发说明.md` 面向非前端开发者的操作说明
