# 第一批数据采集任务

先取得可核实的一小批，不要求立刻收齐全国前50车型。小程序已有手填电池入口，车型不是使用门槛。

## A. 动力再生：先12份同日PDF

固定货物为**完整电池包**，正常状态；如果平台没有整包选项，截图说明实际选项，不自行推定。

| 材料 | 封装 | 重量kg | 文件名建议 |
|---|---|---|---|
| 磷酸铁锂 | 方壳 | 200 / 400 / 800 | YYYYMMDD_LFP_方壳_200kg.pdf（分别保存） |
| 磷酸铁锂 | 软包 | 200 / 400 / 800 | YYYYMMDD_LFP_软包_200kg.pdf |
| 三元 | 方壳 | 200 / 400 / 800 | YYYYMMDD_NCM_方壳_200kg.pdf |
| 三元 | 软包 | 200 / 400 / 800 | YYYYMMDD_NCM_软包_200kg.pdf |

2种材料×2种封装×3种重量=12份。无对应选项则跳过并说明，不造数据。尽量同一天采集，避免把日期变化当重量效应。

一起打包：

- 完整PDF，不只截总价。
- 至少一张完整输入页，以及每个有区别的货物/封装选项页。
- 报价口径说明：是否含税、运输、拆包、拆车，重量是整包/净电芯/其他，报价为单价还是总价，报价有效期。
- 小三元若有独立选项，附分类解释和选项截图；先不要凭软包或Ni/Co黑粉比例给它下定义。

拿到后由Codex提取字段，复算总价/重量，比较200/400/800kg是否同一单价。只有得到验证才扩展质量适用范围；未证实则只对样本重量匹配。第二批再针对出现非线性的区间补点，避免盲目再采50份。

## B. 电池之家：只补口径说明

已有4张截图及200条转录，暂不需要重复抄价。请补：

1. 最新一张表的完整日期标题（当前只知道9月29日采集）。
2. 元/kWh中的kWh是额定电量还是检测剩余可用电量？
3. 价格适用完整电池包、模组还是拆出的电芯？包含哪些拆解/物流/税费？
4. 最新力神三元50Ah材料价96.97元/kWh的原位置放大截图或更正说明。该行当前已隔离，不参与估价。

## C. 车型：首批只做10个有证据的具体配置

用 `data/templates/vehicles.csv` 填写。每条应有：品牌车型+年款+配置、原装电池包型号、材料体系、额定kWh、电池包重量kg、来源链接/文件、核实日期。附工信部公告、厂家资料、包铭牌或可信维修资料；一车多供货包应分条。

不填全国销量前50排名也不影响当前小程序运行。优先真实询价中最多的10个配置。无法确认包型号或重量就保留缺失，不拿车辆整备质量顶替。

## D. 两个网页的补充

NEB `http://www.nebcycling.cn/battery/material`：如你能正常访问，请导出网页PDF或保存完整页面及图表标题、单位、来源和年份。本次可用材料里没有成功抓到原页，不能将暂定成分参数写成实测事实。

Mysteel `https://ldcfl.mysteel.com/`：已有工作簿的12条归档。若补当天行情，请同时带品名、Ni/Co/Li品位、湿/干基、单位、日期、含税口径、区间和样本来源。这些用于材料市场资料与后续校验，不直接等同整包收购价。
