# 后续数据补充任务

当前首批目录已有651个公告车型和683条候选电池配置，数据量不再是当前开发阻塞项。下一轮重点是校准，而不是盲目增加字段。

## 1. 重量主算法复核

现有动力再生数据包含磷酸铁锂、三元、小三元 × 方壳、圆柱、软包，共27条；每组200/400/800kg严格线性。后续如补数据，应保留查询日期、完整输入条件、总价、税费、拆车、运输和货物边界，用于验证元/kg基准是否随时间或交付条件变化。

## 2. 容量校验阈值

当前通过车型库同分类的质量/电量中位数计算等效重量，只展示重量价与容量校验价差异。需要用同一块实际电池的重量、总电量和成交/询价数据，标定“正常差异”和“需要核对”的阈值。在完成前不要让系统自动平均两条结果。

## 3. 地区与里程

产品已确定两者暂不计价。若以后验证是否应恢复影响，需要固定其他条件，分别对武汉、上海、北京及不同里程区间成组采样；只有发现稳定且可解释的规律后才修改算法。

## 4. 车型配置

新增记录至少要有公告车型、整包重量、化学体系、单体外形和来源。总电量可缺失；精确电池包型号未公开时必须留空，不得用车型名或电芯商品名替代。同一公告车型的不同配置分成候选项。

## 5. 材料行情

材料价格只做报告中的静态参考。补充时记录品名、品位、单位、日期、含税口径和来源；这些数据不能直接乘整包重量，也不自动生成理论金属贡献。

定时更新、定时爬取和长期维护任务暂不实施，等待用户明确提出。
